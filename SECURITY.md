# Security and privacy reporting

[English](SECURITY.md) · 简体中文（待补 / pending） · [繁體中文](SECURITY.zh-TW.md)

TamaMe is a source preview. No formal release with a security-maintenance commitment is available.

A private vulnerability-reporting channel has not yet been configured and verified. Do not publicly submit vulnerability details, exploit code, credentials, original conversations or device backups. Before public release, the maintainer must establish and verify a private reporting method and update this page. There is currently no supplied security-contact email or verified reporting URL.

If your credentials were exposed, revoke/rotate them with the relevant provider first, then address files and Git history. Deleting a file, making a repository private or reflashing a device does not revoke leaked credentials. Preserve evidence privately; never post a secret again to reproduce an issue.

Candidate chat/voice logging has been reduced, but upstream, third-party and crash logs may still identify users. Review and redact them manually before sharing the minimum needed for publication or support.
