# 公版美術素材

default-v2 是依確認方向製作的虛構黑髮人物與通用場景，不使用作者真人肖像、私人聲音或特定店家名稱。圖像由內建 imagegen 產生，再透過 prepare_default_art.py 做固定規格的技術轉換。

- avatar/：八張 64×64 RGBA 狀態圖，透明度為 0／255。
- scenes/：健身房、書桌旁、客廳、房間、咖啡廳，各 116×116 RGB。
- profile.json：固定模板與程序疊圖的膚色設定。
- pack/：韌體索引圖、RGB565 palette、遮罩、角色設定、場景 header，以及八圖預覽。

本專案就可授權的此組公版生成美術採 CC0-1.0 分享，完整文本見 LICENSES/CC0-1.0.txt；不主張它具有排他性，也不替使用者取得其他人物、商標或聲音的權利。使用者自行提供的素材不會因為轉換而自動成為 CC0。

原始生成 atlas 與提示詞保留於本機美術審核目錄，不包含私人參考照片；這份發行預覽提供的是已檢查的正式像素檔。裝置呈現仍待硬體驗收。
