# TamaMe support and bug reports

[English](SUPPORT.md) · 简体中文（待补 / pending） · [繁體中文](SUPPORT.zh-TW.md)

This is a source preview. No ready-to-flash general release or response-time commitment is provided. Available public Issues/PR features depend on the repository's actual settings.

Include your board, source commit/package version, exact actions, expected and observed results, and a sanitized minimal error message. For background issues, state whether the option was highlighted, the preview changed, Apply closed the dialog, the selected value remained after reopening, and the result after reboot. Do not submit only a complete serial log.

- Captions without speech: TTS is disabled by default. Read [user settings](docs/user-settings.en.md); local interaction sounds can help check the speaker separately.
- Touch/wardrobe issues: record exact steps first. Clearing pairing or formatting NVS is not a routine troubleshooting step.
- Startup failure or incompatible settings: preserve evidence and private backups. Public firmware does not automatically erase NVS; never blindly reuse partition offsets from the internet.
- Device transfer: no complete clearing flow has passed validation. Installing only the public app does not fully de-identify a device.

Public reports must not contain keys, Wi-Fi passwords, account details, IP/host information, private conversations, raw audio, voice IDs or full Flash images. Follow [SECURITY](SECURITY.md) for security issues.
