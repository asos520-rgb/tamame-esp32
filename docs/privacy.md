# 隱私與資料處理（公開前草案）

[English](privacy.en.md) · [简体中文](privacy.zh-CN.md) · [繁體中文](privacy.md)

公開版不得包含作者或其他使用者的網路密碼、Token、聲音識別碼、私人聲音、對話、配對金鑰或完整設備備份。

訊息回看在既有實作紀錄中是最近八則收到的回覆，存於 RAM、重開機清除；公開版需重做驗證。這不代表遠端服務沒有保存對話，遠端資料處理須依實際服務另外說明。

語音對話可能傳送收音或辨識文字至所設定的服務；TTS 可能傳送回覆文字至語音服務。第三階段依本機程式補上了 [資料流盤點](data-flow.md) 與 [使用者設定](user-settings.md)，尚待完整整合與真實服務驗證。自訂聲音只使用有權使用的聲音，預設不含真人聲音複製素材。

原生與自動化測試資料使用合成或公版素材；單台實機測試曾使用作者既有配對，但私人對話、憑證及原始日誌不納入套件。診斷與錯誤回報不得包含完整對話、密碼或憑證。角色 PNG、生成提示詞與編譯後陣列都可能包含身份特徵，請保留於私人素材目錄。

尚未提供經驗證的全機資料清除流程。重新刷入 app 不等於刪除配對與網路設定；轉讓裝置前需依後續明確的清除說明處理。
