# 隐私与资料处理（公开前草案）

[English](privacy.en.md) · [简体中文](privacy.zh-CN.md) · [繁體中文](privacy.md)

公开版不得包含作者或其他用户的网络密码、Token、声音识别码、私人声音、对话、配对密钥或完整设备备份。

消息回看在既有实现纪录中是最近八则收到的回复，存于 RAM、重开机清除；公开版需重做验证。这不代表远端服务没有保存对话，远端资料处理须依实际服务另外说明。

语音对话可能传送收音或辨识文字至所设置的服务；TTS 可能传送回复文字至语音服务。第三阶段依本机程序补上了 [资料流盘点](data-flow.md) 与 [用户设置](user-settings.zh-CN.md)，尚待完整整合与真实服务验证。自订声音只使用有权使用的声音，默认不含真人声音复制素材。

原生与自动化测试资料使用合成或公开版素材；单台实机测试曾使用作者既有配对，但私人对话、凭证及原始日志不纳入包。诊断与错误回报不得包含完整对话、密码或凭证。角色 PNG、生成提示词与编译后阵列都可能包含身份特征，请保留于私人素材目录。

尚未提供经验证的全机资料清除流程。重新刷入 app 不等于删除配对与网络设置；转让设备前需依后续明确的清除说明处理。
