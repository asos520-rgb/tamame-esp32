# 測試與回退時的設定保留

[English](storage-safety.en.md) · [简体中文](storage-safety.zh-CN.md) · [繁體中文](storage-safety.md)

公版預覽在 NVS 空間不足、版本不相容或初始化失敗時回報錯誤，不自動擦除 NVS。這是資料保留策略，不是自動修復；目前啟動呼叫端仍會因初始化錯誤停止／重啟，尚未提供螢幕上的復原操作。遇到此狀況先停止測試並由私人備份回退，不要用清除配對解決。

| 資料 | 保存位置／策略 |
|---|---|
| 公版寵物金幣、飢餓、占卜與互動進度 | 獨立 NVS namespace `pet_pub_stats`，不搬移或修改原版 `muse_pet_v1` |
| 公版場景、服裝、飾品 | 獨立 namespace `pet_public_v2`，不搬移原版換裝 |
| 音量、亮度、休眠等裝置設定 | 沿用 `muse`，使用者修改仍會影響原版 |
| Wi-Fi、配對與連線資料 | 沿用原 SDK 設定；本次改動沒有將網路或身分複製到公版專屬區 |

首次使用公版會顯示獨立的初始寵物進度。只刷回原 app 時，原版寵物進度仍可使用，但不會回復測試期間修改過的共用設定。要連同設定回到測試前狀態，需要同一設備的完整 Flash 私人快照。

刷寫前先備份當下整顆 Flash、核對兩次讀取及 SHA-256、確認分割表與有效 app 分區。Flash 備份可能包含 Wi-Fi 密碼、配對憑證、內嵌金鑰與私人素材，只能私人保存，不可上傳 Issue 或 Release。

測試時不要解除雲端配對、撤銷憑證、變更帳號、清除設定或啟用會寫入 eFuse 的安全功能。Flash 還原不能復原 RAM、遠端資料或 eFuse。本預覽不含私人備份或刷機腳本。單台設備已完成私人完整快照回復與開機前讀回核對，使用者確認角色、外觀與聲音正常；這不保證其他設備或雲端狀態的回復。
