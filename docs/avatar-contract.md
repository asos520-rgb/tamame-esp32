# 自訂角色素材規格草案

> English summary: Defines the local avatar-pack schema, image requirements and import boundaries; personal portraits are not supplied. Full guide below is in Traditional Chinese.

這是 humanoid64-v1 固定模板的相容規格。已提供本機轉換工具與待整合的獨立渲染器；公版角色美術與裝置動態匯入尚未提供。

## 首版輸入

- 八張 64×64 PNG：boot、idle、listening、thinking、speaking、happy、error、off。
- 必須有透明資訊，建議 RGBA。透明度只能為 0 或 255；不接受半透明。黑色眼睛與黑衣必須保留為不透明像素，不能以黑色代表透明。
- 四邊至少留三個透明像素，不自動縮放、裁切或改背景。工具會攔截空白圖與不符尺寸的圖。
- 八張圖需維持相同頭身比例、臉部位置與衣服範圍。
- 只使用自己有權使用的素材；不要求提供真人照片。
- 私人素材放在 user-assets/，不納入公開檔案清單。轉換後的像素陣列也可能還原樣貌，須同樣視為私人資料。

## 現有座標約束（0 起算，含端點）

| 部位 | 現有範圍 | 用途 |
|---|---|---|
| 左右眼 | x=19–28、34–43；y=31–38 | 閉眼、進食與飢餓表情 patch |
| 嘴部 | x=28–35；y=38–43 | 說話、閉嘴與飢餓表情 |
| 衣服 | x=20–43；y=46–54 | 三套服裝疊圖 |
| 飾品與手部 | 約 y=44–57 | 圍巾、包帶、手與食物疊圖 |

這些座標是首版模板限制，不是任意照片皆能直接套用的保證。設定檔必須保持這組整數座標；任意改座標會被工具拒絕，避免飾品固定幾何出錯。動作會加上少量位移，素材不可貼住邊界。本機工具輸出共用 256 色 palette、八組像素陣列、八組 silhouette 與角色設定 header。

公開候選 renderer 的手／臉頰／嘴部顏色改讀設定檔產生的 skin、cheek、mouth；臉部 patch 與衣服範圍讀取相同角色 header。眼鏡、手部和配件仍依固定模板定位，因此不接受任意身形。膚色設定只影響程序疊圖，不會自動替八張原圖換色，請讓原圖與設定一致。

工具可驗證格式與遮罩，無法自動判斷畫出的眼睛是否位於規定位置，仍需人工核對預覽和動畫。

## 驗收

核對八個狀態、進食、飢餓、三套衣服、圍巾／斜背包／墨鏡，以及五種場景與黑底。需檢查呼吸、跳動、嘴型、透明度和黑色部位不穿透。完成原生渲染及硬體驗證前不宣稱通用角色支援。

以照片製作角色屬自選工作流程；若使用第三方生成服務，必須由使用者知悉照片會傳至該服務。公開專案不應收集或提交使用者照片。
