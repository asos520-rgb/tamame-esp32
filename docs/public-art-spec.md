# 公版場景、服裝與物品規格

> English summary: Specifies the fictional default avatar, five generic scenes, wardrobe/accessory IDs, asset formats and redistribution records. Full guide below is in Traditional Chinese.

正式公版素材已製作並納入 assets/default-v2，實際 C renderer 預覽與首輪實機範圍見 validation-status.md。所有預設人物均採虛構造型，不以作者照片或特徵為原型。

## 場景

| 新公開版 ID | 顯示名稱 | 通用內容 |
|---|---|---|
| 0 | 黑底 | 無場景 |
| 1 | 健身房 | 通用啞鈴、運動器材，不含標誌、鏡中人物或特定店面 |
| 2 | 書桌旁 | 通用桌面、檯燈，不含個人文件、照片、帳號或可辨識窗景 |
| 3 | 客廳 | 通用沙發、植栽、抽象裝飾，不還原私人住宅 |
| 4 | 房間 | 通用床鋪、收納，不含私人照片與地點線索 |
| 5 | 咖啡廳 | 通用咖啡店，不含店名、標誌或特定店家配置 |

每款獨立 116×116 索引圖，搭配該場景的 256 色 RGB565 palette；五款未壓縮 payload 共 69,840 bytes（5 × (116 × 116 + 256 × 2)）。背景不烘入人物、文字或 UI 圖示；人物與字幕優先保持清楚。

新版 ID 與私人韌體舊 ID 意義不同，後續整合應使用獨立版本化儲存設定或明確遷移策略，不可直接讓舊 NVS 數值換成不同場景。本階段不寫入任何裝置設定。

首版每類一款，不納入日夜變化。若有貓，改成通用虛構外觀，不沿用私人寵物特徵。

## 服裝

0＝素色休閒上衣（以公版基礎人物為底）；1＝無標誌運動服；2＝通用圍裙。上衣不使用品牌、制服、名牌或個人化字樣。公開候選 renderer 已移除原品牌像素圖樣，已提供實際渲染預覽，實機驗證範圍見 validation-status.md。

## 飾品、物品與食物

保留無飾品／圍巾／斜背包與可選墨鏡，維持獨立混搭。通用物品及食物種類保留，逐項清理來源與識別資訊；私人耳環特徵不作預設。

## 來源紀錄

正式每組美術需記錄固定素材 ID、原創或來源、允許的再散布範圍、是否經過變更及所需署名。不把私人參考照片、真人肖像、私人店景或可識別生成提示詞作為公開附件。
