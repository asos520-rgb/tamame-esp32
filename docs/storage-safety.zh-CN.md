# 测试与回退时的设置保留

[English](storage-safety.en.md) · [简体中文](storage-safety.zh-CN.md) · [繁體中文](storage-safety.md)

公开版预览在 NVS 空间不足、版本不相容或初始化失败时回报错误，不自动擦除 NVS。这是资料保留策略，不是自动修复；目前启动呼叫端仍会因初始化错误停止／重启，尚未提供荧幕上的复原操作。遇到此状况先停止测试并由私人备份回退，不要用清除配对解决。

| 资料 | 保存位置／策略 |
|---|---|
| 公开版宠物金币、饥饿、占卜与互动进度 | 独立 NVS namespace `pet_pub_stats`，不搬移或修改原版 `muse_pet_v1` |
| 公开版场景、服装、饰品 | 独立 namespace `pet_public_v2`，不搬移原版换装 |
| 音量、亮度、休眠等设备设置 | 沿用 `muse`，用户修改仍会影响原版 |
| Wi-Fi、配对与连线资料 | 沿用原 SDK 设置；本次改动没有将网络或身分复制到公开版专属区 |

首次使用公开版会显示独立的初始宠物进度。只刷回原 app 时，原版宠物进度仍可使用，但不会回复测试期间修改过的共用设置。要连同设置回到测试前状态，需要同一设备的完整 Flash 私人快照。

刷写前先备份当下整颗 Flash、核对两次读取及 SHA-256、确认分割表与有效 app 分区。Flash 备份可能包含 Wi-Fi 密码、配对凭证、内嵌密钥与私人素材，只能私人保存，不可上传 Issue 或 Release。

测试时不要解除云端配对、撤销凭证、变更账号、清除设置或启用会写入 eFuse 的安全功能。Flash 还原不能复原 RAM、远端资料或 eFuse。本预览不含私人备份或刷机脚本。单台设备已完成私人完整快照回复与开机前读回核对，用户确认角色、外观与声音正常；这不保证其他设备或云端状态的回复。
